= teptris (Rust bindings)

image:https://github.com/leptris/teptris-rs/actions/workflows/ci.yml/badge.svg[ci]

**Mission: be the best TOML parser and builder ever made — in C, Ruby,
Rust, and JS — measured, not claimed.** The bar and the family ledger:
https://github.com/leptris/teptris/blob/main/BEST-EVER.md[BEST-EVER.md].

TOML 1.1 for Rust at libteptris speed — hand-maintained FFI over the
C99 engine, no fallback. https://crates.io/crates/teptris[Published on
crates.io]; the descriptor-plan ABI crate ships alongside it as
https://crates.io/crates/teptris-descriptor[teptris-descriptor].

[source,rust]
----
use teptris::{loads, dump, Value};

let v = loads(b"name = \"demo\"\nport = 8080\n").unwrap();
assert_eq!(v.get("name").and_then(Value::as_str), Some("demo"));

let toml = dump(&v).unwrap(); // canonical; parse(dump(v)) == v
----

== Using the crate

The published crate is SOURCE + link directives: your build needs
libteptris available, and your RUNTIME needs it findable (the binding
is dynamically linked — the engine is not bundled).

. *Link time* — install the engine (`cmake --install`, which also
  ships the pkg-config/cmake package files), or point `TEPTRIS_LIB_PATH`
  at a directory containing `libteptris.{dylib,so,dll}`.
. *Run time* — an installed engine is already on the loader path
  (`/usr/local/lib` after a default install); for an uninstalled
  build, point `DYLD_LIBRARY_PATH` (macOS) / `LD_LIBRARY_PATH` (Linux)
  at the engine's build/lib directory.

[source,sh]
----
cargo add teptris
----

== Surface

* `loads(&[u8]) -> Result<Value, ParseError>` — the whole tree as an
  owned `Value` (insertion-ordered tables, all four datetime shapes
  with real `i64`/`u32` fields).
* `dump(&Value) -> Result<String, Error>` — canonical TOML through the
  engine's builder (the emitter stays the single source of truth).
* `dump_json(&Value)` — the toml-test conformance JSON (tagged values).
* `dump_json_natural(&Value)` (0.1.2) — the host JSON view: real
  numbers, booleans, RFC 3339 datetime strings, non-finite floats as
  null. Straight into any JSON parser; the engine's fastest emit.
* **serde** (0.1.6, default feature) — `from_str::<Config>(s)` and
  `to_string(&config)`: parse straight into your structs and back,
  skipping the intermediate `Value` tree. `Value`, `Table` and
  `Datetime` implement `Serialize`/`Deserialize`; datetimes follow
  the `toml` crate's interchange convention (the
  `$__toml_private_datetime` map in foreign formats, a real TOML
  datetime on TOML output). TOML has no null — `None` is a
  serialization error, so skip the field instead.
* `Document` — parse / `to_toml_string` / `to_json_string` (toml-test
  conformance dialect) / `to_json_natural_string` / `to_value`.
* `Descriptor::build(&[PlanRow])` + `walk(&Document)` — compile a plan
  once, materialize only the planned keys in ONE native pass
  (`PlanRow::scalar/collection/raw/nested`); unplanned keys are never
  touched, MISSING rows are absent.
* `ParseError` carries `message` + 1-based `line`/`column`.

== Descriptor plans

[source,rust]
----
use teptris::plan::{Descriptor, PlanRow};

let d = Descriptor::build(&[
    PlanRow::scalar("title"),
    PlanRow::collection("tags"),
    PlanRow::nested("owner", vec![
        PlanRow::scalar("name"),
        PlanRow::raw("meta"),
    ]),
])?;

let doc = teptris::Document::parse(b"title = "d"
[owner]
name = "r"
")?;
let v = d.walk(&doc)?; // only planned keys materialize
----

== Zero-copy note

`teptris_parse` NUL-terminates strings in the input buffer, so the
safe `Document` owns a writable copy of the input for its lifetime
(the C buffer-lifetime contract is contained). `parse_buf(Vec<u8>)`
takes ownership without the extra copy.

== Workspace

`descriptor/` is the `teptris-descriptor` crate — the no_std shared
descriptor-plan ABI (repr(C) mirrors of `plan.h`), the teptris member
of the leptris engine family's shared record layout (leptris XML,
yeptris YAML, teptris TOML/JSON).

== Development

The shared library is resolved by `build.rs`: set `TEPTRIS_LIB_PATH`
to a directory containing `libteptris.{dylib,so,dll}` (CI builds it
from a teptris checkout) or install libteptris on the linker path.

[source,sh]
----
git clone https://github.com/leptris/teptris ../teptris
cmake -B ../teptris/build-shared -S ../teptris -DCMAKE_BUILD_TYPE=Release \
  -DTEPTRIS_BUILD_SHARED=ON -DTEPTRIS_BUILD_CLI=OFF -DBUILD_TESTING=OFF
cmake --build ../teptris/build-shared
TEPTRIS_LIB_PATH=$PWD/../teptris/build-shared/src cargo test
TEPTRIS_LIB_PATH=$PWD/../teptris/build-shared/src cargo bench --bench tier -- ../teptris/bench-corpus
----
